Задание 2 — API-пайплайн: данные → LLM → результат

Автоматический скрипт, который читает отзывы из CSV-файла, отправляет их в LLM через **OpenRouter** (бесплатная модель `openrouter/free`) и возвращает структурированный JSON.

Описание задачи

Скрипт выполняет полный пайплайн:
- Читает данные из "reviews.csv"
- Для каждого отзыва формирует промпт и отправляет запрос в LLM
- Получает строго структурированный JSON (sentiment, topic, summary, pros, cons)
- Сохраняет все результаты в "results.json"

Технологии
- Python 3
- OpenRouter API
- Библиотеки: "requests", "csv", "json".

## Инструкция по запуску

1. Скачайте файлы из репозитория:
   - "task2.py"
   - "reviews.csv"
2. Получите бесплатный API-ключ на https://openrouter.ai/keys
3. Вставьте ключ в файл "task2.py" (замените строку `"your_openrouter_api_key_here"` на ваш ключ).
4. Запустите скрипт.
5. Результат появится в файле "results.json"


Пример входных данных:

В файле "reviews.csv":

id,review_text
1,"Отличный смартфон! Батарея держит два дня, камера просто огонь..."
2,"Телефон средний. Качество сборки нормальное, но батарея садится быстро."
3,"Ужасный опыт. Через месяц начал сильно тормозить и греться."
4,"Хороший бюджетный вариант. Для повседневных задач вполне подходит."
